# QR Code Generator (Weeks 7–8 Assignment)

Flutter-де жасалған QR код генераторы қолданбасы.

## Мүмкіндіктері (Features)
- **Form Validation**: Текст және URL режимі, бос өріс пен қате URL тексеруі.
- **Live State Update**: Мәтін енгізілгенде QR код реалды уақытта өзгереді.
- **Customization**: QR өлшемін баптайтын Slider және түсін таңдау.
- **Themes**: Light және Dark режимдері (ColorScheme.fromSeed).
- **Animation**: Контент немесе түс өзгеретін кезде `AnimatedSwitcher` арқылы плавный анимация.
